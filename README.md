# Cube Runner — 3D игра на Three.js (JavaScript)

Бесконечный неоновый 3D-раннер. Управляй светящимся кубом на трассе:
уклоняйся от красных препятствий, перепрыгивай низкие кубы и собирай
золотые монеты. Скорость постепенно растёт — рекорд сохраняется в браузере.

## Как запустить

Просто открой файл `game/index.html` в любом современном браузере
(нужен доступ в интернет для загрузки Three.js с CDN).

Или запусти локальный сервер:

```bash
cd game
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Управление

| Клавиша            | Действие                          |
|--------------------|-----------------------------------|
| ← → или A / D      | движение влево / вправо           |
| ПРОБЕЛ             | прыжок (низкие кубы перепрыгиваются) |
| R                  | рестарт                           |

## Технологии

- **Язык:** JavaScript
- **Графика:** [Three.js](https://threejs.org/) (WebGL) — сцена, камера, туман, освещение, звёздное небо
- **Геймплей:** процедурная генерация волн препятствий/монет, физика прыжка, AABB-коллизии, HUD и экран смерти, localStorage для рекорда
